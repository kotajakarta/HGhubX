## 1.2.15

### Perubahan
- Daftar dan detail koleksi kini mengambil seluruh data sekaligus.
- Menambahkan “pencarian populer” dengan data API secara langsung.
- Menambahkan kanal “tren” pada halaman kategori, termasuk kategori populer/AI, detail teks-gambar, dan rekomendasi terkait.
- Menambahkan feed mengikuti dan halaman profil pengguna.
- Menambahkan kartu penulis serta rekomendasi yang dapat digeser pada panel detail halaman pemutaran.

### Penyempurnaan
- Bilah bawah diubah menjadi kaca cair (semi-transparan, buram, dan sorotan atas) untuk Android dan iOS.
- Memperbaiki ruang kosong bawah iOS dengan viewport dinamis 100dvh.
- Menyelaraskan mode lanskap iOS: rotasi asli otomatis masuk/keluar layar penuh, penguncian `screen.orientation`, dan kalibrasi posisi setelah layar penuh atau rotasi.
- Mengubah tata letak masonry menjadi CSS Grid untuk menghindari kartu pertama terpotong pada WebKitGTK 2.52.6.

### Artefak build
- Android: paket ABI terpisah untuk arm64 / arm / x86_64
- iOS: IPA tanpa tanda tangan (perlu ditandatangani sendiri)
- Windows: installer + versi portabel
- macOS: DMG universal
- Linux: DEB amd64

Semua commit dan tag telah diverifikasi dengan tanda tangan GPG.

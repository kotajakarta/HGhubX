## 1.2.14

### Perubahan
- Alur pembaruan diubah menjadi “buka halaman unduhan”. Setelah versi baru ditemukan, “Unduh” membuka GitHub Releases di browser sistem; browser dan sistem menangani unduhan serta pemasangan.
- Jika gagal membuka, alamat unduhan otomatis disalin ke clipboard agar dapat ditempel di browser.

### Penyempurnaan
- Menulis ulang kapsul pintasan halaman video. Beberapa tindakan digabung dalam satu grup bergaya kaca dengan pemisah tipis dan label ringkas (episode / penuhi / sesuaikan / lanskap).

### Koreksi
- Alamat repositori pada halaman Tentang diperbarui ke repositori ini dan dibuka langsung di browser.
- Tautan repositori resmi dan kanal unduhan dalam README diperbaiki.

### Artefak build
- Android: paket ABI terpisah untuk arm64 / arm / x86_64
- iOS: IPA tanpa tanda tangan (perlu ditandatangani sendiri)
- Windows: installer + versi portabel
- macOS: DMG universal
- Linux: DEB amd64

Semua commit dan tag telah diverifikasi dengan tanda tangan GPG.

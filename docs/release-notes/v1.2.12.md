## 1.2.12

### Baru
- Saat video lanskap ditemukan dalam mode potret, video ditampilkan secara utuh secara default dengan bilah hitam. Tombol “penuhi / sesuaikan / layar penuh lanskap” tersedia di bagian bawah untuk mengganti mode tampilan atau masuk ke layar penuh lanskap.
- Setelah memperbesar video dengan dua jari, tersedia tombol “pulihkan zoom”.

### Perbaikan
- Memperbaiki ruang kosong di bagian bawah halaman pemutaran iOS setelah toolbar WKWebView ditutup. Tinggi halaman kini dikunci ke tinggi tampilan dan dikalibrasi saat rotasi, keyboard, atau toolbar berubah.

### Artefak build
- Android: paket ABI terpisah untuk arm64 / arm / x86_64
- iOS: IPA tanpa tanda tangan (perlu ditandatangani sendiri)
- Windows: installer + versi portabel
- macOS: DMG universal
- Linux: DEB amd64

Semua commit dan tag telah diverifikasi dengan tanda tangan GPG.

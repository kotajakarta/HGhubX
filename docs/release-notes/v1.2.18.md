## 1.2.18

### Baru
- **Pencarian di dalam kanal**: tombol pencarian pada setiap kanal kini mencari langsung di kanal yang sedang dibuka.
  - Daftar tren menggunakan `type=post`, menampilkan dua kolom sampul dan membuka detail postingan (#34 #38).
  - Kanal lain menggunakan `type=video` dan menampilkan dinding video.
  - Pencarian global pada tab “Pencarian” tetap hanya mencari drama pendek.

### Perbaikan
- **Gagal menyalin laporan diagnostik iOS (#39)**: laporan kini ditulis melalui plugin clipboard resmi Tauri, dengan tombol coba lagi terpisah jika penyalinan gagal. Browser biasa tetap memakai fallback Web Clipboard.

### Artefak build
- Android: paket ABI terpisah untuk arm64 / arm / x86_64
- iOS: IPA tanpa tanda tangan (perlu ditandatangani sendiri)
- Windows: installer + versi portabel
- macOS: DMG universal
- Linux: DEB amd64

Semua commit dan tag telah diverifikasi dengan tanda tangan GPG.

- Beranda, kategori, dan halaman detail tidak lagi dibuat ulang saat mengganti sumber. Posisi saat ini dan status pemutaran tetap dipertahankan.
- Jumlah item per halaman beranda diubah dari 10 menjadi 30 untuk mengurangi penggabungan halaman.

### Artefak build
- Android: paket ABI terpisah untuk arm64 / arm / x86_64
- iOS: IPA tanpa tanda tangan (perlu ditandatangani sendiri)
- Windows: installer + versi portabel
- macOS: DMG universal
- Linux: DEB amd64

Semua commit dan tag telah diverifikasi dengan tanda tangan GPG.
